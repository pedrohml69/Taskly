# Taskly

O **Taskly** é uma aplicação web de organização de tarefas e rotinas, desenvolvida como projeto acadêmico. O projeto utiliza o **Spec Kit** para organizar a definição das funcionalidades e o processo de desenvolvimento.

## Acesso à aplicação

A versão publicada pode ser acessada pelo link:

**[Abrir Taskly](https://pedrohml69.github.io/Taskly/index.html)**

## Funcionalidades

O projeto contempla recursos de organização e gerenciamento da rotina, além dos fluxos de acesso à aplicação.

- **Autenticação:** acesso por e-mail e senha.
- **Cadastro de usuário:** criação de uma conta para utilizar a aplicação.
- **Verificação de e-mail:** fluxo de confirmação do endereço cadastrado.
- **Recuperação de senha:** opção para iniciar o processo de redefinição de senha.
- **Organização de tarefas e rotinas:** recursos para estruturar atividades e horários.
- **Board:** área de organização visual das atividades.

## Tecnologias e ferramentas

- **HTML, CSS e JavaScript:** estrutura, apresentação e comportamento da aplicação web.
- **Firebase Authentication:** autenticação de usuários.
- **Cloud Firestore:** armazenamento de dados e regras de segurança.
- **Spec Kit:** apoio à documentação e ao desenvolvimento orientado por especificações.
- **GitHub Pages:** publicação da aplicação.
